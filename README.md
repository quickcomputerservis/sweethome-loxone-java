# Loxone Java Integration – Maven Fork

This is a fork of [Smarteon/loxone-java](https://github.com/Smarteon/loxone-java), modified to support:

- Java 21
- Maven build system

### Why this fork?

The original project uses Gradle and Java 11. This fork was created to make the code compatible with the SweetHome project, which requires:

- Java 21 support
- Standardized Maven-based builds across all modules

### Changes in this fork

- Added `pom.xml` for Maven compatibility
- Updated source/target compatibility to Java 21
- Minor adjustments to dependencies or structure

---

> This fork may diverge from the original project to meet the evolving needs of the SweetHome ecosystem.
